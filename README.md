# AntSimulator

Symulator mrówek w Pythonie. Repozytorium zawiera dwie wersje:

- **[`v2/`](v2/)** — aktualna, przepisana od zera wersja (Python + pygame + numpy).
  Czysta architektura, algorytm mrówkowy (ACO), testy. **Tu trafiają nowe prace.**
- **[`v1/`](v1/)** — pierwotna, amatorska wersja. Zachowana jako referencja.

Szybki start:

```bash
cd v2
pip install -r requirements.txt
python main.py
```

Szczegóły, sterowanie i opis modelu zachowania: [`v2/README.md`](v2/README.md).
